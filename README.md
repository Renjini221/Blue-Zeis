# Blue-Zeis website (React + Vite)

1. Install Node.js (https://nodejs.org), then in this folder run:
   npm install
2. Start the live dev server:
   npm run dev
3. Build the final site (output goes to the dist/ folder):
   npm run build

Edit text in src/components/*.jsx. Styles are in src/index.css.
Upload the dist/ folder to Netlify or GitHub Pages to publish.
